# Charte graphique - Vite & Gourmand

## Intention visuelle

L'interface doit transmettre une image professionnelle, lisible et rassurante pour un service traiteur.

Le style choisi est simple, clair et accessible :

- fond clair ;
- texte vert profond ;
- accent rouge pour les actions principales ;
- composants Bootstrap pour garantir un rendu responsive rapide.

## Palette de couleurs

| Usage | Couleur | Code |
| --- | --- | --- |
| Texte principal | Vert profond | `#18352f` |
| Fond general | Vert tres clair | `#f8faf7` |
| Fond hero | Vert pale | `#eef5ee` |
| Action principale | Rouge chaud | `#b83232` |
| Surface carte | Blanc | `#ffffff` |
| Bordure douce | Vert grise | `#dce7df` |

## Typographie

Police principale :

```css
font-family: Arial, sans-serif;
```

Le choix est volontairement simple pour conserver une bonne lisibilite et eviter les dependances externes.

## Composants

Les composants principaux sont :

- navbar Bootstrap ;
- boutons `.btn` personnalises ;
- cartes Bootstrap ;
- tableaux Bootstrap ;
- formulaires Bootstrap ;
- alertes Bootstrap.

## Boutons

Le bouton principal utilise :

```css
background: #b83232;
color: #ffffff;
border-radius: 6px;
```

Le rayon de bordure reste inferieur a 8px pour conserver un style sobre.

## Accessibilite

Regles appliquees ou prevues :

- contrastes lisibles ;
- structure HTML semantique ;
- labels visibles sur les formulaires ;
- boutons et liens explicites ;
- mise en evidence des conditions de menu.

Points a completer avant rendu :

- verification RGAA plus complete ;
- focus visibles au clavier ;
- messages d'erreur relies aux champs ;
- textes alternatifs pour les images.

## Maquettes attendues

Le sujet demande :

- 3 maquettes bureautiques ;
- 3 maquettes mobiles.

Proposition de maquettes a produire :

1. Accueil
2. Liste des menus
3. Detail / commande d'un menu

Ces maquettes pourront etre realisees dans Figma, Penpot ou un outil equivalent, puis exportees en PDF.
